# Sahil's game environments

## Orbital Salvage

A standalone, real-time space arcade adventure. Pilot a salvage tug, intercept
drifting cargo, lock it onto your ship, and bring it home safely.

```sh
cd orbital-salvage
npm run dev
```

Open **http://127.0.0.1:5173**. Node 22 or newer is sufficient; no installation,
backend, account, or runtime packages are required.

See [the game README](orbital-salvage/README.md) for controls, missions, tests,
the optional controller API, and static deployment instructions.
